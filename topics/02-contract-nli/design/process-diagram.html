NDA Review Flow

One real NDA, 17 fixed statements. For each statement: does the contract say it, say the opposite, or not mention it, and which sentences prove it? Data: ContractNLI (CC BY 4.0).

Three steps

1 · Route

Which sentences matter?

One call reads the whole contract and picks, for each statement, the spans that could decide it. Later steps see only those.

2 · Parallel

Check all 17 statements at once

One call per statement, all at the same time, each with only its own picked spans.

3 · Chain

Proof first, then the answer

Which picked spans are real evidence? Code checks the numbers. Then: true, false or not mentioned.
