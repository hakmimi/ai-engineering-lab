Eight ways to pick tables, each on the same questions and the same pool. The answer key comes from the benchmark's own SQL, not from me.

The question

"Which dig sites have the best scan quality ratings? Show each site's ID, name and average quality score."

The pool: 971 tables

18 company-style databases (LiveSQLBench-Large), ~54 tables and ~1,000 columns each, cryptic names like vesseltag.
